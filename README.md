Algorithms

Coursework exercises and practical implementations of foundational computer science algorithms.

This repository contains algorithm implementations and performance analysis programs developed as part of coursework in computer science and algorithm design.

Included implementations

File	Language	Algorithm / Topic	Description
FractionalKnapsack.cpp	C++	Fractional Knapsack	Greedy strategy implementation for maximizing profit with a limited knapsack capacity.
FractionalKnapsackCaseStudy.cpp	C++	Fractional Knapsack Case Study	Extended scenario-based analysis of the fractional knapsack problem.
MergeSortBest.c	C	Merge Sort (Best Case)	Merge sort implementation using sorted input to analyze best-case behavior.
MergeSortAvg.c	C	Merge Sort (Average Case)	Merge sort implementation on average-case input and timing analysis.
MergeSortWorst.c	C	Merge Sort (Worst Case)	Merge sort implementation using reverse-sorted input to examine worst-case behavior.
TSPDynamicProgramming.java	Java	Travelling Salesman Problem	Dynamic programming solution that computes the minimum-cost tour and prints the optimal path.
